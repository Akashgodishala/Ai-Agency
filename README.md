# AI Agency

**A done-for-you AI agency: clients bring a use case, we deliver working AI agents.**

This repository is the operating system for the business — the strategy, the
delivery playbook, the reusable agent templates, the tech stack, and the
day-by-day roadmap. It is written for a **non-technical founder**. You do not
need to know how to code to run this. Your job is sales, relationships, and
judgment; the building is done with AI-assisted tools and (later) a small team.

## The one-paragraph version

We start as a **services agency** (done-for-you), not a software platform. We
pick **one niche**, offer a small menu of **proven agent types** (customer
support, lead outreach, knowledge assistant, content, data extraction), and
deliver them for a setup fee plus a monthly retainer. We build with no-code
automation tools + AI, so no big engineering team is needed to start. As the
same use cases repeat, we templatize them — and *that* library of templates
eventually becomes a self-serve **platform**. Services fund the product.

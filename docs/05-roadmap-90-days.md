# 05 — 90-Day Roadmap

> A realistic path from **empty repo** to **first paying clients** in about 90
> days, working part-time. Each phase has a clear goal and a "definition of done."
> Don't rush ahead — each phase makes the next one work.

---

## Phase 0 — Foundation (Week 1–2)

**Goal:** decide what you sell, to whom, and set up the minimum tools.

- [ ] Choose your **niche** (see [Strategy](01-strategy.md)).
- [ ] Choose your **first agent type** to sell (recommend Support or Lead Response).
- [ ] Write your **offer** in one sentence (the outcome, not "an AI agent").
- [ ] Set **starter pricing** (setup + monthly).
- [ ] Register a **domain** + business email.
- [ ] Set up the **minimal stack**: one agent builder + one automation tool + a form tool.
- [ ] I create your **intake form, Agent Spec template, and a project tracker.**

**Done when:** you can say in one sentence who you help, with what, and for how
much — and you have the tools to build one agent.

---

## Phase 1 — Build your demo & proof (Week 3–4)

**Goal:** have one impressive, working agent to show — before you sell anything.

- [ ] Build a **demo agent** for your niche (e.g., a support agent for a
      fictional but realistic dental clinic).
- [ ] Run it through the **test checklist** ([Delivery System](02-delivery-system.md)).
- [ ] Record a **2-minute demo video** of it working.
- [ ] Put up a **simple landing page** describing the outcome + the demo.
- [ ] I help build the demo agent and the landing page.

**Done when:** a stranger could watch your demo and immediately understand the
value.

---

## Phase 2 — First outreach & founding clients (Week 5–8)

**Goal:** land your first 1–3 paying "founding clients" at a discount for
testimonials.

- [ ] Make a list of **30–50 target businesses** in your niche.
- [ ] Send **personalized outreach** (email/DM/call) offering a free demo
      tailored to them. (I can help draft and personalize these.)
- [ ] Do **discovery calls** using the intake form.
- [ ] Deliver **1–3 pilots** by hand through the 6-station delivery system.
- [ ] Get a **testimonial + written case study** from each.

**Done when:** you have your first paying clients and proof it works for real
businesses.

> Reality check: outreach is a numbers game. Expect to contact many to close a
> few. This is normal — the demo does the heavy lifting.

---

## Phase 3 — Systematize (Week 9–12)

**Goal:** turn one-off delivery into a repeatable machine and raise prices.

- [ ] Turn your delivered agents into **reusable templates**.
- [ ] Document each station's **checklist** so the process is consistent.
- [ ] Set up **monthly reporting** for clients (retention driver).
- [ ] **Raise prices** for new clients now that you have proof.
- [ ] Consider your **second agent type** or **second niche**.
- [ ] Decide whether to bring on a **contractor** for delivery.

**Done when:** you can deliver the same agent type in a fraction of the original
time, and clients are renewing.

---

## Beyond 90 days — Toward the platform

Once you've delivered the same agent type ~10–20 times and it's highly
templatized:

- [ ] Build a **self-serve intake** where clients configure their own agent from
      your templates.
- [ ] Add a **client dashboard** (usage, conversations, reports).
- [ ] Automate the parts of Stations 1–4 that are now identical every time.
- [ ] This growing system **is** the platform — funded by your services revenue.

---

## The rhythm that makes this work

- **Weekly:** review progress against the current phase's checklist.
- **Sell before you build big.** Never build a feature no client has asked and
  paid for.
- **One niche, one agent, one channel** until it's working — then expand.
- **Use me continuously** — for demos, outreach copy, custom builds, testing,
  reporting, and to explain anything technical in plain English.

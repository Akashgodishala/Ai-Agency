# Archive — the services-era plan (superseded)

These files are from the project's first direction: a **done-for-you services
agency** (we hand-build agents per client). The founder clarified the real
vision — a **self-serve platform** where anyone generates their own agent — so
the repo was re-planned around that.

Nothing here is deleted because parts remain useful:

- `demo/frontdesk-demo.html` — the AI Front Desk demo. Its concept lives on as a
  **starter template in the platform's gallery**.
- `site/index.html` — the agency landing page. Its missed-revenue calculator and
  visual language may be reused for platform marketing.
- `docs/` — the services-era strategy. Still a valid playbook if the founder
  ever wants a services arm alongside the platform.
- `templates/`, `outreach/` — intake/outreach kits for the services model.

**Current plan:** see the repository root `README.md` and `docs/`.

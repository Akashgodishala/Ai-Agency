## Delivery checklist (per client)
Copy this block for each client you're building for.

### [Client Name] — Delivery
- [ ] **Intake** — discovery call done, intake form filled
- [ ] **Design** — Agent Spec drafted
- [ ] **Design** — client approved the Spec
- [ ] **Build** — agent assembled
- [ ] **Build** — channels connected (site / SMS / calendar)
- [ ] **Test** — passed the test checklist
- [ ] **Deploy** — live on agreed channels
- [ ] **Deploy** — client trained + owner's manual sent
- [ ] **Support** — monitoring set up
- [ ] **Support** — first monthly report sent
